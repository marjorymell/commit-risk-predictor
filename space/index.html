Commit Risk Predictor

Estimates how likely a commit is to introduce a bug. Trained on the git history of vtex/faststore, with bug-introducing commits identified by the SZZ algorithm. Meant to prioritise testing, not to block merges.

The model runs entirely in your browser: a logistic regression exported from scikit-learn as plain JSON. It matched a Random Forest on unseen commits, so the simpler model ships.

Fields you do not set use the median commit of the dataset.

Source code, tests and evaluation: github.com/marjorymell/commit-risk-predictor
